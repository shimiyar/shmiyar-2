# شیمی یار (Shimi Yar) — دستیار جامع آموزش و کنکور شیمی

اپلیکیشن موبایل بومی و تخصصی آموزش شیمی ویژه دانش‌آموزان دبیرستان (پایه‌های دهم، یازدهم و دوازدهم) و داوطلبان کنکور سراسری تجربی و ریاضی با طراحی مدرن الهام‌گرفته از زبان طراحی iOS Dark Mode.

---

## ۱. انتخاب استک فنی و چرایی آن (Tech Stack)

برای پیاده‌سازی این اپلیکیشن از **Native Android با زبان Kotlin و فریم‌ورک Jetpack Compose + Material 3** استفاده شده است.
**دلایل اصلی انتخاب:**
1. **عملکرد ۱۰۰٪ بومی و پرسرعت (Native Performance):** اجرای کامپوننت‌های تعاملی پیچیده مانند انیمیشن ورق زدن سه‌بعدی فلش‌کارت‌ها (3D Flip Animation) و رندر همزمان جدول تناوبی ۱۱۸ عنصری در ۱۸ ستون بدون هیچ‌گونه افت فریم (۶۰/۱۲۰ فریم بر ثانیه).
2. **پشتیبانی بی‌نقص و سخت‌افزاری از راست‌به‌چپ (True Persian RTL):** بدون مشکلات رایج فونت و جهات در کراس‌پلتفرم‌ها.
3. **حجم بسیار بهینه و کارکرد کاملاً آفلاین:** حجم نهایی فایل نصبی (APK) کمتر از ۳۰ مگابایت بوده و تمامی داده‌ها (عناصر، فلش‌کارت‌ها، جزوات، واژه‌نامه) به صورت فایل‌های محلی JSON در دارایی‌های داخلی (Assets) تعبیه شده‌اند بدون نیاز به ذره‌ای اینترنت.

## ۲. ساختار پروژه (Project Structure)

```
app/
├── src/main/
│   ├── assets/
│   │   ├── elements.json       # داده‌های کامل تمام ۱۱۸ عنصر جدول تناوبی
│   │   ├── flashcards.json     # بیش از ۱۳۰ فلش‌کارت در ۱۰ دسته‌بندی موضوعی
│   │   ├── education.json      # ۱۰ فصل آموزشی کامل با هر ۸ بخش اختصاصی
│   │   └── glossary.json       # واژه‌نامه جامع تعاریف و اصطلاحات شیمی
│   ├── java/com/example/
│   │   ├── MainActivity.kt     # ناوبری ۵ تب، دراور، هدر با نوار XP و دیالوگ‌ها
│   │   ├── data/
│   │   │   ├── model/          # مدل‌های داده‌ای عناصر، فلش‌کارت، آموزش و گیمیفیکیشن
│   │   │   └── local/          # DataLoader برای خواندن دارایی‌ها و PreferencesHelper
│   │   ├── ui/
│   │   │   ├── theme/          # رنگ‌های iOS Dark Mode، تایپوگرافی و شیپ‌ها
│   │   │   ├── components/     # هدر ShimiHeader، آنبوردینگ، Paywall و نکته روز
│   │   │   ├── screens/        # صفحات ۵ تب (جدول، آموزش، فلش‌کارت، واژه‌نامه، پروفایل)
│   │   │   └── viewmodel/      # ShimiYarViewModel مدیریت پایدار وضعیت
│   └── AndroidManifest.xml
```

## ۳. قابلیت‌ها و تب‌های اپلیکیشن

1. **آنبوردینگ ۴ اسلایدی:**
   - اسلاید ۱: معرفی جدول تناوبی ۱۱۸ عنصر
   - اسلاید ۲: آموزش جامع دبیرستان
   - اسلاید ۳: فلش‌کارت‌های موضوعی
   - اسلاید ۴: فعال‌سازی خودکار ۷ روز هدیه رایگان پرو
2. **تب ۱: جدول تناوبی (جدول):**
   - جدول ۱۸ ستون در ۱۰ سطر شامل ردیف‌های لانتانیدها و آکتینیدها
   - فیلتر جستجوی آنی با نام فارسی، انگلیسی، نماد و عدد اتمی
   - بردر رنگی ۳dp متناسب با ۱۰ دسته عنصری
   - Bottom Sheet جزئیات عنصر با نمودار مشخصات، یادداشت شخصی محلی و تحلیل کنکوری
3. **تب ۲: آموزش دبیرستان (آموزش):**
   - کنترل سگمنتد پایه‌های دهم، یازدهم و دوازدهم (۱۰ فصل)
   - آکاردئون ۸ بخشی برای هر فصل: خلاصه، فرمول‌ها (کد LTR)، نکته طلایی، نکته کنکوری، تکنیک حفظی، اشتباهات رایج، مثال حل‌شده، سوال کنکور
   - قفل بلورشده بخش‌های ۳ تا ۸ برای کاربران رایگان و نوار پیشرفت ۲۵٪
4. **تب ۳: فلش‌کارت‌ها (فلشکارت):**
   - بیش از ۱۳۰ فلش‌کارت در ۱۰ دسته با انیمیشن Flip سه‌بعدی
   - شمارنده کارت‌های امروز، یادگرفته‌شده و کل
   - دکمه‌های «🔁 دوباره» و «✓ بلد شدم» با جشن پایان دسته
5. **تب ۴: واژه‌نامه (واژهنامه):**
   - دسته‌بندی مفاهیم پایه، خواص دوره‌ای، پیوند، واکنش، الکتروشیمی، شیمی آلی
   - سرچ سریع تعاریف و اصطلاحات
6. **تب ۵: پروفایل و گیمیفیکیشن (پروفایل):**
   - آواتار طلایی پرو، شمارنده XP و Level
   - ماموریت‌های روزانه با پاداش XP
   - گرید ۸ نشان افتخار (Badges)
   - کارت‌های خرید اشتراک ۶ ماهه و ۱ ساله
7. **سیستم Smart Paywall:**
   - باز شدن بعد از ۳ بار کلیک روی محتوای قفل یا مشاهده ۵ عنصر
   - تایمر معکوس ۲ ساعت و ۴۵ دقیقه، نظرات ۵۰۰+ دانش‌آموز، باندل ۵ درس کنکور با ۶۰٪ تخفیف و دکمه فعال‌سازی ۷ روزه رایگان

## ۴. نحوه بیلد و اجرا (Build Instructions)

```bash
# بیلد پروژه و تولید فایل نصبی APK
gradle assembleDebug

# اجرای تست‌های منطق برنامه
gradle testDebugUnitTest
```
فایل APK کامپایل‌شده در مسیر `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.
